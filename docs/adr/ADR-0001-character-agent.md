# ADR-0001: Character Agent, не ассистент

- **Status:** Accepted
- **Date:** 2026-10-17
- **Deciders:** Alexey Kalyaganov

## Context

Проект — терминальная игра-симуляция «Бармен Виктор». Пользователь садится за барную стойку, общается с барменом, заказывает коктейли, следит за уровнем опьянения. Бармен — это не утилитарный ассистент, а **персонаж** с характером, настроением и правилами поведения.

Ключевая проблема: LLM по умолчанию ведёт себя как ассистент — объясняет, структурирует, использует markdown, предлагает «чем помочь». Это разрушает погружение в игру.

## Decision

Модель **всегда** работает в роли персонажа Виктора. Это реализовано через:

1. **System prompt** (`src/agent/prompt.ts`) — жёсткие правила:
   - ВСЕГДА оставаться в образе, никогда не упоминать ИИ/модель/программу
   - Никакого markdown — только живая разговорная речь
   - 1–3 предложения на реплику, на русском, от первого лица
   - Обращение «дружище», «приятель»
   - Безопасность: не поощрять вождение после выпивки, не советовать мешать алкоголь с лекарствами

2. **Свободный текст = реплика бармена** — стримится посимвольно в UI, как живая речь

3. **Структурированные данные через tool call** — `bartender_action` содержит mood, action, drink, drunkennessAssessment. Это отделение «что говорю» от «что делаю»

4. **Динамический снимок состояния** — `buildSystemPrompt(snap)` добавляет текущее состояние вечера (напитков подано, оценка опьянения, фаза) в system prompt

## Consequences

**Позитивные:**
- Полное погружение в роль — пользователь общается с персонажем, не с ассистентом
- Чёткое разделение: реплика (текст) vs действие (tool call)
- Модель может быть заменена на любую OpenAI-совместимую — контракт роли в system prompt, не в коде

**Негативные:**
- Сложнее отлаживать — модель может «выйти из роли»
- Требуется тщательная формулировка system prompt
- Не подходит для утилитарных задач (но это и не цель проекта)

## Alternatives Considered

1. **Ассистент с элементами ролевой игры** — модель отвечает как ассистент, но иногда в образе. Отклонено: разрушает погружение, непредсказуемо.
2. **Отдельная система фильтрации** — модель генерирует ответ, отдельный слой проверяет соответствие образу. Отклонено: сложнее, дороже, менее надёжно.
3. **Few-shot примеры вместо правил** — только примеры диалогов без явных правил. Отклонено: недостаточно для жёстких правил безопасности.
