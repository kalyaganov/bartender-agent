# ADR-0002: Единый OpenAI-compat адаптер

- **Status:** Accepted
- **Date:** 2026-10-17
- **Deciders:** Alexey Kalyaganov

## Context

Проект должен работать с разными LLM-провайдерами: OpenRouter, DeepSeek, Groq, xAI, Together, локальные модели. Изначально существовал каталог из 11 провайдеров с отдельной конфигурацией для каждого.

Проблемы исходного подхода:
- 11 веток кода для каждого провайдера
- Сложность добавления нового провайдера
- Разные форматы запросов/ответов
- Дублирование логики стриминга и обработки ошибок

## Decision

**Один адаптер `OpenAIProvider`** (`src/agent/providers/openai.ts`), работающий через `baseURL` с любым OpenAI-совместимым эндпоинтом.

Ключевые принципы:
- **Контракт `StreamPart`** (`src/agent/providers/types.ts`) — единый формат событий: `text-delta`, `reasoning-delta`, `tool-call-delta`, `tool-call`, `finish`, `error`
- **Конфигурация — плоская схема** в `preferences.json`: `{endpoint, token, model, thinking, extraHeaders}`
- **BYOK (Bring Your Own Key)** — ключи пользователя, расходы пользователя, никаких env API keys в коде
- **Адаптер маппит универсальный контракт** в специфику OpenAI API (SSE, tool calls, reasoning)

## Consequences

**Позитивные:**
- Новый провайдер = просто указать `endpoint` + `token`, без изменений в коде
- Единая логика стриминга, обработки ошибок, retry
- Проще тестировать — один адаптер вместо 11
- Пользователь сам выбирает провайдер и модель

**Негативные:**
- Ограничен OpenAI-совместимыми эндпоинтами (но их большинство)
- Некоторые провайдеры имеют специфичные ограничения (ZAI режектит named tool_choice, DeepSeek-thinking режектит `required`)
- Требуется ручная настройка endpoint и токена

## Alternatives Considered

1. **Каталог провайдеров** (исходный подход) — отдельная конфигурация и код для каждого. Отклонено: дублирование, сложность поддержки.
2. **Использование Vercel AI SDK** — готовый слой абстракции. Отклонено: тяжёлый зависимость, не все провайдеры поддерживаются, сложнее кастомизировать стриминг.
3. **Прямые API-вызовы без адаптера** — каждый провайдер напрямую. Отклонено: невозможно поддерживать.
